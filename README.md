
# AgileFlow

Sistema web acadêmico para registro, consulta e acompanhamento de demandas de TI, desenvolvido com práticas de engenharia de software colaborativa.

## Sobre o projeto

O AgileFlow é um MVP (Produto Mínimo Viável) desenvolvido no contexto acadêmico da disciplina de Engenharia de Software Colaborativa, da Brás Cubas. A proposta é facilitar o registro e o acompanhamento de demandas de Tecnologia da Informação, reunindo informações sobre as solicitações e suas atualizações em um único sistema.

## Objetivo

Organizar o acompanhamento das demandas de TI, permitindo que as informações sejam registradas e consultadas de maneira clara, estruturada e acessível.

## Tecnologias previstas

- Python 3.12: linguagem principal.
- Flask: desenvolvimento da aplicação web.
- PostgreSQL: banco de dados previsto.
- pytest: testes automatizados.
- Git e GitHub: controle de versão e colaboração.
- GitHub Actions: execução automatizada dos testes.

## Funcionalidades previstas

- Registrar demandas de TI.
- Consultar demandas cadastradas.
- Registrar atualizações sobre o andamento das demandas.
- Organizar as informações para facilitar o acompanhamento.

## Qualidade e desenvolvimento

O projeto utiliza controle de versão com GitHub, testes automatizados com pytest e integração contínua com GitHub Actions. O desenvolvimento também prevê revisão de código por Pull Requests e validação de usabilidade com representantes da comunidade.

## Situação atual

A estrutura inicial da aplicação Flask, a rota da página inicial, o teste automatizado inicial e o fluxo de integração contínua foram configurados. O fluxo de testes apresentou execução bem-sucedida no GitHub Actions.

As funcionalidades de registro e consulta de demandas, a integração com PostgreSQL e as validações externas ainda precisam ser implementadas ou concluídas.

## Contexto acadêmico

Projeto desenvolvido para fins educacionais na disciplina de Engenharia de Software Colaborativa, da Brás Cubas.
